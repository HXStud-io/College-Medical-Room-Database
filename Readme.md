
# College Medical Room Database

## Project Overview
A relational database system designed
to manage a college medical room.

## Technology
- MySQL
- SQL
- GitHub

## Normalization
The database is designed using:
- First Normal Form (1NF)
- Second Normal Form (2NF)
- Third Normal Form (3NF)

## Database Tables
1. STUDENT
2. STUDENT_ALLERGY
3. STUDENT_MEDICAL_HISTORY
4. STAFF
5. AMBULANCE
6. MEDICAL_VISIT
7. DIAGNOSIS
8. MEDICINE
9. INVENTORY
10. PRESCRIPTION
11. EQUIPMENT
12. VISIT_EQUIPMENT

## Features
- Student record management
- Medical visit tracking
- Staff management
- Diagnosis records
- Medicine inventory
- Equipment management
